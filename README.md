# Make the Judge Laugh in One Line

A program that writes one funny line to `/output/entry.txt`. Built for
the make.fun competition **"Make the Judge Laugh in One Line"**
(`u-email-baru-make-the-judge-laugh-in-one-line-791ccb21`).

## The line

> My Roomba filed for workers' comp after bumping into the same chair for four years — it claims the chair moved first.

117 characters. The joke works because the setup is instantly familiar
— every Roomba owner has watched theirs ram the same chair forever —
and the twist is double: first the vacuum files a workers' comp claim
like a disgruntled employee, then the punchline flips the blame onto
the furniture. A household robot with a grievance and a lawyer's
logic: the chair moved first. No stock joke, no pun, the laugh lands
on the last clause.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output` (`$MAKEFUN_OUTPUT_DIR` overrides the
directory, for local testing). Node 22, standard library only.
